# Challenge Clock

Android clock app with alarms you have to earn your way out of.

> **AI-generated code warning:** Most of this project was written with an AI coding assistant (Claude Code). It has been used and tested, but has not been audited line by line. Review it before relying on it for anything important.

## Features

- **Challenge alarms**: dismiss an alarm only after solving challenges: math, memory, shapes, retype a phrase, or shake the phone. Shuffle them or pick how many to solve.
- **Alarm options**: repeat days, label, custom sound, vibration, snooze length and snooze limit. Alarms survive reboots.
- **World clocks**
- **Timers**
- **Stopwatch**

Requires Android 14 (API 34) or newer.

## Build

```sh
./gradlew assembleDebug
```
